# 目录结构说明（soybean-admin）

以树结构的方式整理项目目录职责，适合快速定位代码位置。

## 目录树

```text
soybean-admin/
├─ .github/                      Issue/PR 模板与 CI 工作流
├─ .vscode/                      VS Code 工作区配置
├─ build/                        Vite 构建相关配置与插件封装
│  ├─ config/                    构建期配置（proxy/buildTime 等）
│  └─ plugins/                   Vite 插件集合（router/unocss/unplugin/html 等）
├─ packages/                     monorepo 内部包（workspace 引用）
│  ├─ alova/                      Alova 请求封装与类型
│  ├─ axios/                      Axios 请求封装与类型
│  ├─ color/                      颜色工具与调色板算法
│  ├─ hooks/                      通用组合式 hooks
│  ├─ materials/                  可复用 UI 物料（AdminLayout/PageTab 等）
│  ├─ scripts/                    CLI 脚本（cleanup/changelog/release 等）
│  ├─ uno-preset/                 UnoCSS preset（shortcuts 等）
│  └─ utils/                      通用工具（storage/crypto/nanoid 等）
├─ public/                       公开静态资源（构建时原样拷贝）
├─ src/                          应用主代码
│  ├─ assets/                     资源（imgs、本地 svg-icon）
│  ├─ styles/                     全局样式（css/scss）
│  ├─ components/                 通用组件
│  │  ├─ common/                  基础通用组件（Provider/异常页/语言/全屏等）
│  │  ├─ advanced/                高级组件（表格列设置/表头操作等）
│  │  └─ custom/                  自定义组件（SvgIcon/CountTo 等）
│  ├─ constants/                  常量定义（app/business/reg 等）
│  ├─ enum/                       枚举定义
│  ├─ hooks/                      应用内 hooks
│  │  ├─ common/                  通用 hooks（router/form/table/echarts 等）
│  │  └─ business/                业务 hooks（auth/captcha 等）
│  ├─ layouts/                    布局体系（base/blank + modules）
│  ├─ locales/                    i18n（语言包、dayjs、naive 映射等）
│  ├─ plugins/                    应用初始化插件（assets/loading/dayjs 等）
│  ├─ router/                     路由体系（guard/routes/elegant）
│  │  ├─ guard/                   路由守卫（权限/进度/标题等）
│  │  ├─ routes/                  路由定义（builtin/custom/generated 整合）
│  │  └─ elegant/                 elegant-router 生成/转换（imports/routes/transform）
│  ├─ service/                    Axios 请求层（request + api）
│  ├─ service-alova/              Alova 请求层（request + api + mocks）
│  ├─ store/                      Pinia store（modules + plugins）
│  ├─ theme/                      主题体系（settings/vars/preset）
│  ├─ typings/                    类型声明（全局/环境/api/router 等）
│  ├─ utils/                      应用工具（service/storage/icon/common 等）
│  ├─ views/                      页面（_builtin/manage/plugin/function 等）
│  ├─ App.vue                     根组件
│  └─ main.ts                     应用入口
├─ vite.config.ts                 Vite 主配置
├─ uno.config.ts                  UnoCSS 配置
├─ tsconfig.json                  TS 配置
├─ pnpm-workspace.yaml            workspace 配置
└─ package.json                   脚本与依赖
```

## 推荐查找路径

- 入口与初始化：`src/main.ts`、`src/plugins/*`、`src/App.vue`
- 路由与菜单：`src/router/*`、`src/store/modules/route/*`
- 请求与拦截器：`src/service/request/*` 或 `src/service-alova/request/*`
- 主题与 NaiveUI theme：`src/store/modules/theme/*`、`src/theme/*`
- 可复用 UI：`packages/materials/*`、`src/components/*`
